# Modelli della scuola

Qui puoi mettere il modello di verifica della tua scuola (file .docx), così non devi allegarlo ogni volta.

- Usa un nome chiaro, per esempio `modello_verifica_scuola.docx`.
- Se ci sono più modelli (per esempio uno per le prove pratiche), mettili tutti: la skill chiede quale usare.
- Il modello deve essere vuoto: nessun nome di studenti, nessun voto.

Se la cartella è vuota, la skill chiede il modello all'inizio.
